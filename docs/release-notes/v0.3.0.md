## Baru di v0.3.0

### Sambung dengan kode panel (semua platform)
- Ketik **kode 6/8 digit** atau **8 huruf** yang tampil di layar panel — tidak perlu tahu IP.
  Spasi diabaikan (`834 109` = `834109`).
- **Android & iOS:** tombol **Scan QR** untuk memindai kode QR di panel.
- Port bawaan kini **3056** (sesuai panel Lango). Kolom PIN hanya muncul bila Anda mengetik IP manual.

### Touchback (Windows & macOS)
- Sentuh panel untuk mengendalikan laptop: ketuk = klik, geser = drag, tekan lama = klik kanan,
  tombol panah/OK di remote = panah/Enter. Indikator **TOUCHBACK ACTIVE** saat aktif.
- Bisa dimatikan di **Pengaturan › Touchback**.
- **macOS:** izinkan argocast di *System Settings › Privacy & Security › Accessibility*.

### iOS (baru)
- Aplikasi Flutter + ekstensi **Screen Broadcast** (ReplayKit) dengan encoder H.264 VideoToolbox.
- Dirilis sebagai `.ipa` **tanpa tanda tangan**: pasang lewat Xcode atau Sideloadly dengan Apple ID
  gratis (perlu dipasang ulang tiap 7 hari).

### Perbaikan
- PIN yang diketik dengan spasi tidak lagi ditolak.
- iOS 15: ekstensi siaran tidak lagi gagal karena API khusus iOS 16.

## Catatan

- **Audio belum didukung** — cast hanya mengirim gambar. Format audio panel Lango belum berhasil dipetakan.
- Touchback belum tersedia di Android; iOS tidak mengizinkan aplikasi mengendalikan sentuhan.
- Installer Windows dan macOS belum ditandatangani/dinotarisasi; APK Android ditandatangani dengan kunci debug.
- Installer desktop menyertakan FFmpeg (GPL, libx264); lisensi di `ffmpeg-LICENSE.txt` dalam folder aplikasi.
