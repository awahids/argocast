## Baru di v0.2.0

### macOS (baru)
- Aplikasi desktop yang sama dengan versi Windows (Electron), untuk Apple Silicon dan Intel.
- Tangkap layar lewat AVFoundation; FFmpeg sudah termasuk sesuai arsitektur Mac.
- Meminta izin **Local Network** (pencarian panel) dan **Screen Recording** (tangkap layar).
- Klik ikon Dock untuk membuka kembali jendela saat cast berjalan di latar belakang.

### Android (baru)
- Aplikasi Flutter: cari panel otomatis (mDNS), sambung manual via IP, masukkan PIN.
- Tangkap layar dengan MediaProjection + encoder H.264 hardware; tetap berjalan di latar belakang
  dengan notifikasi berisi tombol **Hentikan**.
- Pengaturan nama perangkat, resolusi, frame rate, dan kualitas; panel terakhir dipakai disimpan.

### Umum
- Pesan error tangkap layar lebih jelas (termasuk petunjuk izin di macOS).
- Installer untuk semua platform kini dibuat otomatis oleh GitHub Actions.

## Instalasi singkat

- **Windows:** jalankan `.exe` → bila muncul *"Windows protected your PC"* klik **More info → Run anyway**.
- **macOS:** buka `.dmg` → seret ke Applications → buka sekali → **System Settings › Privacy & Security › Open Anyway**
  (atau `xattr -dr com.apple.quarantine /Applications/argocast.app`) → izinkan Local Network & Screen Recording.
- **Android:** buka `.apk` di ponsel → izinkan *Install unknown apps* → Install.

Detail langkah dan pemecahan masalah ada di [PANDUAN.md](https://github.com/awahids/argocast/blob/v0.2.0/docs/PANDUAN.md).

## Catatan

- Installer Windows dan macOS belum ditandatangani/dinotarisasi; APK Android ditandatangani dengan kunci debug
  (cukup untuk dipasang manual, belum untuk Google Play).
- Belum tersedia: iOS, audio, reverse cast, kontrol sentuh, upload file, moderator.
- Installer desktop menyertakan FFmpeg (GPL, libx264); lisensi di `ffmpeg-LICENSE.txt` dalam folder aplikasi.
