Prototipe pertama **argocast** — aplikasi Windows untuk cast layar laptop ke panel interaktif yang memakai protokol Lango/XBH (LRTSP/2.0).

> ⚠️ **Pre-release.** Baru diuji terhadap *mock panel* lokal, **belum** terhadap panel Lango asli. Kirimkan log (`-v` di CLI) bila koneksi ke panel gagal.

## Unduh
**`argocast-Setup-0.1.0.exe`** — installer Windows 10/11 64-bit (FFmpeg sudah termasuk).

SHA-256: `84fe164ab6b2f3b94419035920a124c9be2d84869e7eeefc8bf485eef07dd988`

## Fitur
- Menemukan panel otomatis di jaringan (mDNS `_airgo._tcp`) atau sambung manual via IP + PIN
- Cast layar desktop (H.264, 1080p/720p, 15–30 fps, 3 pilihan kualitas)
- Layar LIVE dengan timer, FPS, bitrate; berjalan di system tray saat jendela ditutup
- Pengaturan nama perangkat, resolusi, frame rate, kualitas
- Installer per-user (tanpa admin), shortcut Desktop & Start Menu, uninstaller

## Instalasi
1. Jalankan `argocast-Setup-0.1.0.exe`.
2. Installer belum ditandatangani: jika muncul **"Windows protected your PC"**, klik **More info → Run anyway**.
3. Peluncuran pertama bisa butuh beberapa detik (Windows Defender memindai FFmpeg).
4. Laptop dan panel harus berada di jaringan yang sama.

Instal senyap: `argocast-Setup-0.1.0.exe /S`

## Belum tersedia
Audio, reverse cast, kontrol sentuh/mouse, upload file, mode moderator, layar virtual, pilih satu jendela/monitor.

## Lisensi pihak ketiga
Installer menyertakan FFmpeg (build `ffmpeg-static`) yang memuat komponen GPL (libx264). Lisensi ada di `resources\ffmpeg-LICENSE.txt` di folder instalasi; source FFmpeg tersedia di https://ffmpeg.org/download.html.
